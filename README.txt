Step-by-Step Guide: How to Package RoomFlow as a Desktop Application

Step 1: Open Terminal in Your Project Folder
npm init -y
-------------------------------------------------------------------------------------------------------------
Step 2: Install Electron & Electron Builder
npm install electron electron-builder --save-dev
-------------------------------------------------------------------------------------------------------------
Step 3: Create "main.js" (Desktop App Window Setup)

const { app, BrowserWindow } = require('electron');
const path = require('path');

function createWindow() {
  const win = new BrowserWindow({
    width: 1300,
    height: 850,
    title: "RoomFlow • Client & Room Manager",
    autoHideMenuBar: true, // Hides browser menu bar for a clean native app look
    webPreferences: {
      nodeIntegration: false,
      contextIsolation: true
    }
  });

  // Load your index.html file
  win.loadFile(path.join(__dirname, 'index.html'));
}

app.whenReady().then(createWindow);

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') {
    app.quit();
  }
});

-------------------------------------------------------------------------------------------------------------
Step 4: Configure package.json (In Vs Code you get this under your project folder once you run the above commands)

{
  "name": "roomflow-app",
  "version": "1.0.0",
  "description": "RoomFlow Desktop Application",
  "main": "main.js",
  "scripts": {
    "start": "electron .",
    "build": "electron-builder --win nsis"
  },
  "build": {
    "appId": "com.roomflow.app",
    "productName": "RoomFlow",
    "directories": {
      "output": "dist"
    },
    "files": [
      "index.html",
      "app.js",
      "style.css",
      "main.js"
    ],
    "win": {
      "target": "nsis"
    }
  },
  "devDependencies": {
    "electron": "^28.0.0",
    "electron-builder": "^24.0.0"
  }
}
-------------------------------------------------------------------------------------------------------------
Step 5: Test the Desktop App Locally
npm start
-------------------------------------------------------------------------------------------------------------
Step 6: Build the .exe File for Other Computers
npm run build
-------------------------------------------------------------------------------------------------------------
Note: Once the command finishes building, you will see a new dist folder in your project directory:

Inside dist/, you will find: RoomFlow Setup 1.0.0.exe.
